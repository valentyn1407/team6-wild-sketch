# Wild Sketch

A responsive website developed as a team project.

## Live Demo

🔗 [View Live Demo](https://valentyn1407.github.io/team6-wild-sketch/)

## About the Project

Wild Sketch is a team-developed web project focused on building a responsive,
user-friendly interface based on a Figma design.

The project is built using modern frontend development tools and collaborative
Git workflows.

## Technologies

- HTML5
- CSS3
- JavaScript
- Vite
- Git and GitHub

## Features

- Responsive layout for mobile, tablet, and desktop devices
- Interactive mobile navigation menu
- Interactive UI elements and animations
- Semantic and accessible HTML
